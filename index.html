About This Project

This project analyzes how students from different academic majors use ChatGPT between September 2025 and March 2026. The dataset combines ChatGPT conversation histories from multiple majors, including Math/Engineering, Physics, Physics-Math, Physics/Engineering and Biology, and examines differences in usage behavior, interaction patterns, and prompt complexity.

Cluster Analysis Results

Cluster Suggested Name Description
Cluster 0 Conceptual STEM Understanding Focused on understanding why math/physics concepts work, especially differential equations, electricity, and conceptual explanations.
Cluster 1 Applied Problem Solving & Lab Reports Contains long homework problems, physics labs, differential equation applications, and report-writing tasks.
Cluster 2 Step-by-Step Learning & Clarification Mostly short follow-up questions asking for detailed explanations, examples, and walkthroughs.
Cluster 3 Advanced Equation Solving Practice Heavy focus on solving differential equations, IVPs, systems, substitutions, and procedural calculus practice.
Cluster 4 Strategy, Interpretation & Study Guidance Questions about how to know which method to use, interpreting graphs/slope fields, study confusion, and conceptual guidance.
