About This Project

This project analyzes how students from different academic majors use ChatGPT between September 2025 and March 2026. The dataset combines ChatGPT conversation histories from multiple majors, including Math/Engineering, Physics, Physics-Math, Physics/Engineering and Biology, and examines differences in usage behavior, interaction patterns, and prompt complexity.

Data Description

This project uses a dataset of ChatGPT conversation logs collected from students across multiple academic majors, including Math/Engineering, Physics, Physics/Engineering, Physics-Math, and Biology. Only user messages are included in the analysis, where each record represents an individual prompt sent by a student during a ChatGPT conversation.

The dataset focuses on user-generated content to analyze how students interact with ChatGPT across different academic disciplines.

Data Scope

To ensure fair comparison across majors, the analysis is restricted to the period:

September 2025 – March 2026

This time window standardizes usage across all groups and avoids bias from uneven data collection periods.

Key Insight

The most interesting finding is that ChatGPT usage differs more in how students interact than in how often they use it.

Math-Engineering and Physics-Engineering students generate the highest message volume and tend to write longer, more detailed prompts, suggesting step-by-step problem solving behavior.

In contrast, Biology and Physics students generally use shorter and more concise prompts. Computer Science stands out with relatively few but extremely long prompts, indicating more focused but intensive usage sessions.

Overall, while usage timing appears similar across majors, interaction style varies significantly across disciplines.

New Technique: Text Clustering (TF-IDF (Term Frequency-Inverse Document Frequency) + K-Means)

This technique was used to uncover hidden patterns in unstructured ChatGPT messages.

First, messages were converted into numerical form using TF-IDF, keeping the top 500 most important words while reducing noise.

Next, K-Means clustering (k=5) grouped similar messages into clusters representing different types of student prompts.

Finally, a normalized cross-tabulation by major was created to compare how different academic groups distribute across clusters.

A treemap visualization was used to display hierarchical proportions of cluster usage across majors.

Limitations

This dataset is based on a limited number of students per major and is not a fully representative sample of each academic discipline. As a result, the findings may not generalize to all students within these majors.

Additionally, students use a variety of AI tools beyond ChatGPT, such as Claude and Google Gemini. Therefore, this analysis reflects only ChatGPT usage patterns, not overall AI usage behavior.

Future Work

With more time and data, I would collect a larger and more diverse set of ChatGPT conversation logs across multiple majors and a wider range of students.

This would improve representativeness and allow for a more accurate understanding of how different academic backgrounds influence AI interaction styles.
